KuroMoe Veil — portable build
=============================

Запуск:
  - двойной клик по Start.bat
  - или anime_client_cpp.exe

НЕ запускай gen_icon.exe — это служебная утилита сборки, не приложение.

Распакуй всю папку целиком (нужны platforms/, qml/, Qt DLL рядом с exe).

Настройки читаются из config.ini в этой же папке (прокси выключен).
JacRed: https://jac.red
(можно поменять в Настройках)

Файл config.ini.example — образец без личных данных.
