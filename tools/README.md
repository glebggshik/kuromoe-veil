# tools/ — НЕ runtime

Всё в этой папке — **инструменты разработки и отладки**, а не часть приложения:

- `*.py`, `*.js` — probe/дампы Kodik, JacRed, Sukebei, Playwright и т.п.
  Запускаются вручную при отладке конкретного источника; в сборку и
  в packaging не попадают.
- `*.html` — сниппеты/фикстуры разметки для разбора парсеров.

Приложение (runtime) — только `src/`, `qml/` (без `qml/sandbox/`), `resources/`.

Сборка: см. `README.md` в корне.
